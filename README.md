# 🍽️ Velvet Bite - Restaurant Web Application

## 🚀 Overview
A modern web platform designed to explore the menu, book tables, and place food delivery orders.

## 🛠️ Tech Stack & Structure
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend & Server:** PHP, XAMPP Local Server
- **Core Files:** 
  - `index.php` - Homepage
  - `menu.php` - Food & beverage menu
  - `resturant.php` - Restaurant details
  - `orderdelevery.php` - Delivery services
  - `booktable.php` - Table reservations
  - `navbar.php` - Dynamic navigation
