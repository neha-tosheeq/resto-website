# Velvet Bite - Restaurant Web Application

A modern web platform designed to explore the menu, book tables, and place food delivery orders.

### Project Structure

```text
pages_php/       -> Main application pages (index, menu, resturant, booktable)
style.css        -> Global styling and UI design
script.js        -> Client-side interactivity
imges/           -> Local image assets (Ignored in Git tracking)

# 1. Place the project folder in your local server directory
Move the 'resto-website' folder to: C:\xampp\htdocs\

# 2. Start the local server
Open XAMPP Control Panel and start the 'Apache' module.

# 3. Access the application in browser
Navigate to: http://localhost/resto-website/pages_php/index.php

Frontend    -> HTML5, CSS3, JavaScript
Backend     -> PHP (Session Management)
Server      -> XAMPP Local Server (Apache)
